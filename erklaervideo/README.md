# erklaervideo/

Briefing-Ablage für das Erklär-/Imagevideo des **Garden Park Guest House**
& **Butterfly Cottage** und der interaktiven Highland-Karte.

- **[BRIEFING.md](./BRIEFING.md)** — das vollständige Briefing für den
  Video-Chat: Auftrag, Über uns, Karte, inhaltliche Highlights, Marken-Look
  und die noch offenen Entscheidungen.

## So nutzt du es im Video-Chat

1. Repo hinzufügen: „**add repo f5yct67kcv-source/GardenParkMap**“.
2. Auf das Briefing verweisen: es liegt unter `erklaervideo/BRIEFING.md`
   (alternativ die Markdown-Datei direkt anhängen).
3. Video per **Higgsfield-Konnektor** erstellen — zuerst
   `get_workflow_instructions` prüfen, dann `generate_video` /
   `generate_image` / `generate_audio`.
4. Video-Material: eigene Fotos (auf Anfrage) sowie Screenshots/Screen-
   Recording aus `1.4_Interaktive_Mappe_mit_Route-Features.html` (Repo-Wurzel).
