GARDEN PARK GUEST HOUSE - INTERAKTIVE KARTE
============================================

INHALT
------
1.3_Interaktive_Mappe_Standard.html
    Die Hauptversion: Karte, Whisky & Gin, Day Trips, The Way to
    Grantown, Discover Grantown, FAQ (6 Sprachen), Plan My Day,
    SEO-optimiert (statisches HTML + FAQ-Schema fuer Google & AI).

1.4_Interaktive_Mappe_mit_Route-Features.html
    Alles aus 1.3 PLUS: Route in Google Maps oeffnen, Route teilen,
    Wetter-Hinweis zur Route, Route drucken.
    >>> EMPFOHLENE VERSION <<<

QR-Rezeptionskarte.html
    Druckvorlage fuer Rezeption/Lounge/Zimmer. Im Browser oeffnen,
    finale Web-Adresse der Karte eintragen, Format waehlen, drucken.

QR-Rezeptionskarte.pdf
    Fertiges PDF. ACHTUNG: Der QR-Code zeigt fest auf
    https://www.garden-park.co.uk/map - nur verwenden, wenn die
    Karte genau unter dieser Adresse online geht. Sonst die
    HTML-Version verwenden (dort ist die URL anpassbar).

INSTALLATION
------------
1. EINE der beiden HTML-Dateien auswaehlen (Empfehlung: 1.4)
2. Datei auf den Webserver hochladen (FTP, Hosting-Panel, etc.)
3. Optional umbenennen, z.B. zu "map.html" fuer eine schoene URL
4. Von der Hauptseite verlinken, damit Google sie findet

Die Datei ist komplett eigenstaendig - kein Setup, keine Datenbank,
keine Abhaengigkeiten. HTML, CSS, JavaScript, alle 6 Sprachen und
alle Daten stecken in der einen Datei.

HINWEISE
--------
- Wetterdaten kommen live von open-meteo.com (kostenlos, kein Key)
- Kartenmaterial von OpenStreetMap/CARTO (kostenlos)
- Die ETA-Gebuehr im FAQ (GBP 20) bitte vor Go-Live auf gov.uk pruefen
